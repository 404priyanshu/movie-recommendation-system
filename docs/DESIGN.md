# CineMatch visual specification

Built using the frontend-app-builder and imagegen skills, with the built-in image generation tool. Concept: `design-concept.png`.

Direction: warm editorial cinema journal. Ivory #f6f5ef background, dark green #203b32 text, sage #637069 secondary text, lime #d8edac match labels, fine #d8dbd2 rules. Georgia display typography and Arial UI type keep local startup independent of font services.

Primary screen: simple film mark and two navigation links; two-column headline and cinematic triptych; numbered full-width taste band; numbered recommendations section; quiet footer. No account controls. All text and interactions are native HTML/React. Art is illustrative, not an official poster. Mobile stacks the hero and controls, with two recommendation columns. Results extend the same editorial spacing and typographic system into poster cards with native disclosure explanations.

Concept prompt: Complete desktop CineMatch screen with the supplied headline, search, selected favorites, Find My Movies button, numbered taste/results bands, original space/desert/mountain cards, and empty state. Premium ivory/green editorial serif style; no invented metrics or unrelated sections.

Asset prompt: 1536x1024 triptych with equal edge-to-edge panels: ringed planet/astronaut in midnight teal, orange desert mesas/traveler, blue alpine lake/pines. Fine lithographic texture; no lettering, gaps, borders, or mockup shadows. The source is used via background-position to present each genre panel. Generated artwork is the only generative-AI element; recommendations never use an LLM.
